No extension? Use the bookmarklet

Drag the button below to your bookmarks bar, then go to any site you're logged into and click it — cookies are sent to Site Scout instantly.

⬡ Grab Cookies → Site Scout

Can't see the bookmarks bar? Press Ctrl+Shift+B (Win) or ⌘+Shift+B (Mac)

1

Tap Copy code below.

2

Bookmark any page, then edit that bookmark and paste the code as the URL. Save it as Grab Cookies.

3

Go to the site you're logged into, open bookmarks, tap Grab Cookies — done.

⚠ Only non-HttpOnly cookies are readable from JS. For HttpOnly tokens use the desktop extension + Paste & Scan.

1

Install the extension

1

Click Download Extension above — save the .zip file anywhere.

2

Unzip it — you should get a folder called site-scout-extension (or similar) containing manifest.json.

3

Open Chrome / Edge / Brave and go to chrome://extensions.

4

Turn on Developer mode (toggle in the top-right corner).

5

Click Load unpacked → select the unzipped folder (the one with manifest.json inside). Done — the Site Scout icon appears in your toolbar.

2

Send tokens to Site Scout

1

Go to the site you want to open a session on (e.g. instagram.com) and make sure you're logged in.

2

Click the Site Scout icon in your browser toolbar.

3

Your site appears in the list. Click it — the right tokens are pre-selected automatically.

4

Hit Send to Site Scout — the session field on this page fills instantly.

3

Open your session

1

Back on Site Scout, the URL field is already filled with the site domain.

2

The Session tokens panel is open with your tokens ready.

3

Click Open Session — a browser window launches, already logged in via a US proxy.
